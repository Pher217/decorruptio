# Name & certification-mark policy (ADR-000 G8)

The code is MIT-licensed and may be forked. The **guardrails are not enforceable
in forked code** — anyone can strip the review gate. Our only defenses are social
and legal, not technical:

- **"Decorruptio" is a project name/mark.** A fork that removes the review gate,
  auto-publishes named allegations, or otherwise violates ADR-000 may **not** use
  the Decorruptio name or imply endorsement.
- A **methodology-certification mark** is granted only to instances that honor the
  guardrails (data minimization, review gate, tiered publication, provenance).

This file exists so the limitation is stated honestly rather than pretending the
code enforces ethics.
